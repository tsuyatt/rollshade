# rollshade starter

The smallest game-like setup for [rollshade](https://www.npmjs.com/package/rollshade): a hero, an enemy, two torches and three spells with hit events and status effects.

```sh
npx degit tsuyatt/rollshade/examples/starter my-game
cd my-game
npm install
npm run dev
```

Click to throw a fire bolt, press 1 for an ice nova and 2 for a thunder beam. Everything is in `main.js` (about 100 lines). Replace the capsules with your own models: `hand` and `chest` are empty objects placed where spells start and land.
